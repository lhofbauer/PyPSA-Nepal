# PyPSA-Nepal

PyPSA-Nepal is an open-source power system model for Nepal based on the PyPSA framework. It aims to support integrated power system planning and policy.

> [!Warning]
> The model is in its early development stages and is currently under heavy development.
> It requires further work across most parts of the model, including validation, and, hence, is
> currently still limited in its application. Model structure,
> data, and everything else may change without notice.
